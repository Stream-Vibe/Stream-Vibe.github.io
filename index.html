01Motivation

Why proactive assistance is hard

Today’s streaming assistants wait for a request that names the event to watch for. Real users state goals and change them as they go.

1

The intent is often implicit

“Help me when I get stuck” names no trigger; the assistant must decide when to help.

2

The task state keeps changing

Without tracking progress, assistants repeat, give outdated advice, or miss steps.

3

Requests are revised mid-task

Users add, replace or interrupt requests; assistants keep following the first one.

02Task

Three levels of user intent

Graded by how explicit the intent is and whether it changes mid-task.

Level 1 · Explicit

The user names a condition or event; the assistant responds when it occurs.

Let me know when the water starts boiling.
silent
The water is boiling now.
Single EventTransitionRecurring
Level 2 · Implicit

The user gives a goal; the assistant infers when and how to help from the video and task progress.

Help me make these mini jam rolls.
silent
Trim off the crusts before spreading the jam.
Now flatten the bread with a rolling pin.
GuidanceLearningMonitoringTool use
Level 3 · Dynamic

The request is revised, extended or interrupted while the task is under way.

Recap my progress after each stage.
Stage 1 done: centre crease made.
Actually, just tell me when I make a mistake.
Fold the corners in first, then the tab.
RevisionCompositionInterruption

04StreamVibe-Bench

Benchmark construction and evaluation

Physical and digital task videos. Gemini-3.8-Flash proposes help points with time windows and reference replies; a sample is kept only if four reviewers all approve it.

600 explicit · 2,000 implicit · 1,500 dynamic samples. Scored on timing (P / R / F1 / FPR) and quality (answer score, content F1).

05Method

StreamVibe-VL and StreamVibe-Harness

A streaming model decides when and what to say; a harness keeps track of the requests.

One second of inference. The Harness updates the state; the model stays silent until a help point.

HStreamVibe-Harness

Tracks every request, task progress and past replies; retrieves the relevant history.

1Adaptive streaming SFT

Balances silence and response so the model neither stays mute nor over-talks.

70K + 768K samples

2Localized trajectory RL

GRPO on short rollouts around help points, rewarding timing, content and consistency.

15K tasks
